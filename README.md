## The entry

> This morning the power went out, so my neighbour knocked with two cups of coffee, and we drank them on the stairs while our dark street slowly woke up — nobody checked a phone once.

## How it works

`main.ts` (Node 22) writes that single line to `/output/entry.txt`. No network, no input files, no randomness — the same warm line on every run.

Run it locally:

```sh
node main.ts
cat /output/entry.txt
```
